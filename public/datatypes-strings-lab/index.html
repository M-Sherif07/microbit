Topic 08

Letters and numbers

Use numbers to calculate and strings for text. Python decides the type from the value you write, and quotes make all the difference.

Activity 1

What type is it?

Integers are whole numbers, floats have a decimal point, and strings are text in quotes. Sort each value: watch out for numbers in quotes.

Activity 2

Add or join?

+ adds numbers but joins strings, and * repeats strings. Predict what each program prints, then run it. The Variables panel shows each value's type.
